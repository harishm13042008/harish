| Section | Details |
|---|---|
| **Customer Segment(s)** | Students, hobby storytellers, educators, social media and content creators without drawing skills |
| **Jobs-to-be-Done / Problems** | Convert story ideas into comics quickly and affordably with consistent visuals |
| **Triggers** | Class assignment, content deadline, wish to share a story visually |
| **Emotions Before** | Frustrated, discouraged, time-pressured |
| **Emotions After** | Confident, creative, satisfied |
| **Available Solutions** | Manual drawing, hiring artists, template-based comic makers |
| **Problem Root Cause** | Comic creation needs writing plus art skills; existing tools do not automate both |
| **Our Solution** | Comic Craft AI generates script, characters and panels from a simple prompt using Gemini models |
| **Channels of Behaviour (Online)** | Web app, social media sharing, educational communities |
| **Channels of Behaviour (Offline)** | Classroom demos, college events, word of mouth |
| **Differentiator** | End-to-end story-to-comic automation with style selection and panel-level editing |
