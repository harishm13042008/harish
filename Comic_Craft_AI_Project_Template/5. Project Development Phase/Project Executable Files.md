| S.No | File / Command | Purpose | How to Run |
|---|---|---|---|
| 1 | requirements.txt | Lists dependencies (streamlit, google-genai, pillow, reportlab, python-dotenv) | `pip install -r requirements.txt` |
| 2 | .env | Stores GEMINI_API_KEY | Create file with `GEMINI_API_KEY=your_key` |
| 3 | app.py | Main application | `streamlit run app.py` |
| 4 | tests/test_all.py | Automated tests | `pytest tests/` |

## Execution Steps

| Step | Action |
|---|---|
| 1 | Clone the repository and open the project folder |
| 2 | Create a virtual environment and install requirements |
| 3 | Add Gemini API key in the .env file |
| 4 | Run `streamlit run app.py` |
| 5 | Open the local URL in a browser, enter a story idea, select style and generate the comic |
